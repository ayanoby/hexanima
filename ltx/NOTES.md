## Transformer (AVTransformer3DModel, 48 layers, audio+video)
- video stream hidden 4096 = 32 heads x 128; audio stream 2048 = 32 heads x 64; in/out channels 128 both; ff video 4096->16384->4096 (GELU tanh, no ff bias), audio ff 2048->8192->2048.
- per block (block0 = 388 MB, x48 = 18.6 GB): attn1 (video self), attn2 (video cross to text, kv from caption 4096), audio_attn1, audio_attn2 (audio cross to text, 2048), audio_to_video_attn (q 4096->2048, k/v 2048, out 2048->4096), video_to_audio_attn (q 2048, k/v 4096->2048), ff + audio_ff. Every attention has q/k RMSNorm over the full width and gated attention (to_gate_logits [32, dim]: per-head gate), biases on q/k/v/out.
- AdaLN: scale_shift_table [9,4096] (video), [9,2048] (audio), prompt tables [2,..], a2v ca tables [5,..]; global adaln_single (timestep -> 36864 = 9x4096), audio_adaln_single (18432), prompt_adaln_single, av_ca_* gates/scale-shifts; rope type "split", theta 10000, max_pos [20,2048,2048] (t,h,w), audio rope 1D; causal_temporal_positioning; keyframes_abs_pos_embedding.
- before the DiT: Gemma 4 12B hidden states -> caption projection -> 8-layer embeddings connector (1D transformer, 128 learnable registers, video width 4096 and audio width 2048 variants), norm PER_TOKEN_RMS.
- scheduler RectifiedFlow, distilled: 8 + 3 steps, CFG 1 (second 3 steps after the x2 spatial upscaler).

Architecture: 48 layers, hidden 3840, 16 q heads; 40 sliding layers (head_dim 256, 8 kv heads, rope theta 1e4 rotate_half, window 1024 = irrelevant for prompts < 1024 tokens) and 8 full layers (every 6th: idx 5,11,...,47: head_dim 512, ONE kv head, v = raw k_proj output (k_eq_v, no v_proj), rope theta 1e6 'proportional': only the first 64 of 256 angle pairs rotate, rest identity); q/k RMSNorm with weight, v RMSNorm without weight, attention scaling 1.0 (NO 1/sqrt(d)), causal; MLP gelu_tanh(gate)*up -> down (15360); sandwich norms: x += post_attn_norm(attn(input_norm(x))); x += post_ffn_norm(mlp(pre_ffn_norm(x))); x *= layer_scalar (scalar per layer 0.05-0.35, whole stream incl. residual); RMSNorm = x*rsqrt(mean+1e-6)*w (no +1); embeddings * sqrt(3840), BF16 [262144, 3840] (tied lm head, softcap 30 — but next-token logits of this LTX-tuned checkpoint are NOT meaningful (saturated, same tokens for any prompt), do not use them as a test).

Then the 8-layer 1D connectors (in the DiT file: video_embeddings_connector / audio_embeddings_connector, 128 learnable registers replace padded positions). Tokenizer: HF tokenizer of the file (tokenizer_json inside the safetensors), BOS id 2 first, max 1024 tokens, left padded + masked (padding does not matter if only the real tokens are run: rope is relative).
Cost: 48 layers x ~190 MB int8 = ~9.1 GB + embeddings 1.5 GB + projections 2.3 GB per prompt. After the fix: 'red fox running through snow at sunrise' gives a fox in golden snow light, 'black and white cat sleeping on a green sofa' a cat on green (samples/).
LESSON: always check end-to-end semantics (different prompts -> different content), not only numerical agreement between two implementations of the same assumption.

## Video VAE on the phone NPU: DONE 2026-11-15 (QNN HTP v69) -> the whole text-to-video path runs on the phone
Decoder = ltx-core VideoDecoder with the 'video-vae-conv-bf16' file (conv decoder, 408 M params, ~10 GMAC per latent voxel). HTP rejects rank-5 elementwise / RMSNorm ops ("Failed to validate op rms_norm_0 ... has incorrect Rank 5", also Sigmoid), so vae/tiledec.py rewrites it with video = [T, C, H, W] (frames in the batch axis): Conv3d(3x3x3, replicate temporal pad) = one Conv2d(3C -> Cout) on the concatenation of frames t-1, t, t+1; PixelNorm on dim 1; DepthToSpace = pixel_shuffle + frame interleave by Gather with the dropped first frame; conv_out channels r/q swapped for pixel_shuffle; per-channel un-normalise inside the graph. Equals ltx-core to 2.8e-6 in fp32 (python tiledec.py check). export_tile.py NAME T H W -> ONNX (1.6 GB, needs ~7 GB RAM: free the ltx-core decoder first, an OOM kill hit once), build_ctx.sh NAME -> QNN context (fp16, v69, 825 MB, no unsupported ops once rank 4). Fixed tile 3 latent frames x 8x8 latents -> 17 frames x 256x256 px.
Runner vae/runner/lvae.cpp (QNN, derived from kvae.cpp; build.sh via docker): `tile Z 3 8 8 OUT` (one tile, 660 ms on the phone, vs torch 1.5e-3) and `dec TOK.f32 3 HL WL OUT.f32` (DiT tokens [3*HL*WL][128] -> fp32 [17][3][32HL][32WL] in [-1,1], spatial tiles with overlap 2 latents and linear blend). Phone files: /data/local/tmp/lv/{lvae,vtile.bin}, QNN libs from /data/local/tmp/klt/qnn.
Result: 17 frames 384x512 decoded in 4.1 s on the phone; vs the torch decode mean abs diff 0.6/255 (99th percentile 3-4). Whole clip on the phone: text ~16 s + DiT 8 steps ~71 s + VAE ~4 s = ~91 s (samples/phone_decode_sheet.png, fox_phone.mp4, cat_phone.mp4).
